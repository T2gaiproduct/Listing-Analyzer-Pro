Product: Ecommerce Guru (Listing Analyzer Pro)

Status: Planning only — not implemented until approval.
Prepared: 26 October 2026 (IST) · Version 1.0

1. What this document is for

Seven client areas: Excel attributes, categories, bulk content, multi-marketplace content, revenue calculator, A+ graphics, policy-compliant AI. This document lists what exists today, which PostgreSQL tables change, and new tables — without breaking current users.

Principle: New fields are optional. audits.generated_content, current Excel columns, and single-product Generate content stay the default.
